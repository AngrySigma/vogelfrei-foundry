Vogelfrei

A game system for Foundry VTT v14

Vogelfrei is an OSR game of Wounds and Stamina, Weapon Skill and ascending Armour Class. This system provides character, monster and vehicle sheets, equipment compendia, dice rolls, party travel tools and the campaign Chronicle.

The Vogelfrei rulebook is the authority for the rules.

Installation

  1. In Foundry VTT, open Game Systems → Install System.
  2. Paste this manifest URL and click Install: 
    https://github.com/AngrySigma/vogelfrei-foundry/releases/latest/download/system.json
  3. Create a world and select Vogelfrei as its game system.

Alternatively, download system.zip from the latest release and unpack it into Data/systems/vogelfrei/ in Foundry's user data directory. Manual installs do not update automatically.

Characters and equipment

Create a character Actor to track ability scores, Wounds, Stamina, saving throws, exploration skills, money and equipment. Click rollable values on the sheet to make checks, saves and attacks. The character generator can help create a level-1 character.

The included compendia contain weapons, armour, adventuring gear, containers, animals and vehicles. Drag entries onto a character or into the world to use them. Equipped armour contributes to the Armour Class variants shown on the sheet, and encumbrance is calculated in points.

Monster Actors use Wounds and their own attack and save values. Vehicle Actors track propulsion, cargo and travel details.

During play

Combat: use the combat tracker for individual or group initiative. Attack rolls use the appropriate Armour Class variant; damage is applied through the Wounds and Stamina pipeline.

Party: open the Party window from the Actors Directory or token controls. Its Roster and Formation tabs track members, animals, vehicles, marching order, travel and experience shares.

Chronicle: open the Chronicle from the token controls to track world time, watches, dungeon turns, encounters and upkeep.

Macros: drag an owned Item or a Roll Table to the hotbar to create a macro. New macros call the system's game.vf API.

Support and development

Report bugs and requests in the issue tracker. Include reproduction steps, the Foundry and Vogelfrei versions, and relevant browser console errors.
