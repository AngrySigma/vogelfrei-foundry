# Vogelfrei for Foundry VTT

A game system for [Foundry VTT](https://foundryvtt.com) v14 that plays **Vogelfrei**, an OSR game of
Wounds and Stamina, Weapon Skill and ascending Armour Class.

## Installation

In Foundry, go to *Game Systems → Install System* and paste this manifest URL:

```console
https://github.com/AngrySigma/vogelfrei-foundry/releases/latest/download/system.json
```

Or download `system.zip` from the [latest release](https://github.com/AngrySigma/vogelfrei-foundry/releases/latest),
unpack it into `<Foundry data>/Data/systems/vogelfrei/`, and restart Foundry. Installed this way, the
system won't update itself.

Report bugs and requests in the [issue tracker](https://github.com/AngrySigma/vogelfrei-foundry/issues).
To work on the code, see [CONTRIBUTING.md](CONTRIBUTING.md).
